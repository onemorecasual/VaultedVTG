VAULTED VTG STARTER WEBSITE

FILES
- index.html: page content and structure
- styles.css: layout, colors, typography, mobile styling
- script.js: demo product inventory, category filters, and demo bag

HOW TO PREVIEW
Open index.html in a modern web browser. An internet connection is needed for Google Fonts and the sample remote product photos.

HOW TO CUSTOMIZE PRODUCTS
Open script.js and edit the products array. Each item has:
- id: unique number
- name: product name
- category: Vintage, Y2K, Denim, or Modern
- price: number in USD
- badge: short label
- image: direct URL to your product photo

Replace the sample image URLs with URLs to photos you own or are authorized to use. The current sample prices and items are examples only.

BEFORE PUBLISHING
- Confirm your address and add current store hours.
- Verify Instagram URL and contact information.
- Test on phone and desktop.
- The bag is a front-end demo only; it does not save orders, manage inventory, calculate shipping, or accept payments.
- For real checkout, connect an e-commerce platform or payment provider and configure taxes, shipping, policies, and order fulfillment.

FREE HOSTING
You can publish a static site with GitHub Pages. Create a GitHub repository, upload these files, enable Pages in repository settings, and configure your custom domain in the Pages settings. At your domain provider, add the DNS records GitHub instructs you to add. DNS instructions depend on the exact domain and provider.
